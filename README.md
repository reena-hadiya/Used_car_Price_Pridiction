# Used Car Price Prediction 🚗

#deployment on rendor :https://used-car-price-pridiction-1.onrender.com
A Machine Learning project that predicts the **estimated price of a used car** based on details such as brand, model, fuel type, city, distance travelled, car age, brand rank, and yearly usage.

### Tech Stack

* Python
* Pandas & Scikit-learn
* Jupyter Notebook
* Flask
* HTML & CSS
* Joblib

### Features

* User-friendly web interface
* Used car price prediction using a trained ML model
* Brand and model selection
* Flask backend for prediction
* Saved ML model and preprocessing pipeline

### Project Structure

```text
Used_Car_Price_Prediction/
├── notebook/
├── models/
├── backend/
└── frontend/
```

The project combines **Machine Learning + Flask + HTML/CSS** to provide a simple web-based used car price prediction system.
